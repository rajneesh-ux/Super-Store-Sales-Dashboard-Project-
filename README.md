# 🛒 SuperStore Sales Analysis | Power BI Dashboard

An interactive Power BI project focused on analyzing SuperStore sales, profit, and order performance. The dashboard explores business performance across product categories, regions, and time periods using data visualization and KPI analysis.

![SuperStore Sales Dashboard](Dashboard/dashboard.png)

---

## 📌 Project Overview

This project uses SuperStore sales data to explore business performance and answer questions such as:

- Which product categories and regions generate the highest sales?
- Which products and regions contribute the most profit?
- How do sales and profit change over time?
- Which areas show strong sales but low profitability?

---

## 🎯 Project Objectives

- Analyze sales, profit, and order performance.
- Compare performance across categories, sub-categories, and regions.
- Identify top-performing products and profitability trends.
- Present key business metrics through an interactive dashboard.
